# Tableau Dashboard

**CKD Population Health Analysis**

An interactive Tableau dashboard exploring chronic kidney disease patterns across demographic groups and selected health risk factors.

The dashboard includes:
- CKD classification and key performance indicators
- CKD proportion by age group
- CKD proportion by diabetes status
- CKD proportion by smoking history
- CKD proportion by BMI category

**Methodology:** Results are based on unweighted sample proportions among adults with classified CKD status. They should not be interpreted as nationally representative prevalence estimates.
