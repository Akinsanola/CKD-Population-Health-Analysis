# Power BI Dashboard

Interactive CKD analysis developed in Microsoft Power BI.

The dashboard includes:
- Four KPIs: Classified Adults, CKD Cases, Without CKD, and CKD Rate.
- CKD proportion by age group.
- CKD proportion by diabetes status.
- CKD proportion by smoking history.
- CKD proportion by BMI category.

The dashboard uses DAX measures for calculating CKD proportions and counts.
